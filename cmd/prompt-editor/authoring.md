Treat each prompt edit as a revision of the instructions an agent receives.

Before editing:

1. State the behavior to change and which agents and situations it affects.
2. Read the complete relevant sources and composed prompts. Follow their uses
   across roles, conditions and input producers. Include related skills and
   references; check when agents actually load them. Resolve gaps in the
   context report that matter to the intended behavior.
3. Assess the existing instructions. Identify what already covers the behavior,
   what is missing or conflicting, and where the change belongs. Decide what
   to keep, rewrite, consolidate, move or remove before adding instructions.

After editing, reread the complete affected prompts. Check their order,
priorities, terminology, examples and cross-references together. Remove stale
or redundant instructions. Judge whether each recipient can understand and
act on the result with the context available in that situation.

Use diffs to locate changes and full text to assess the result. Rendering and
compatibility checks verify composition; they do not establish clarity or
agent behavior. When presenting changes, open the draft or review in the
browser and explain the intended behavior, the overall revision and what
remains unverified. Follow docs/prompt-authoring.md for commands and checks.
