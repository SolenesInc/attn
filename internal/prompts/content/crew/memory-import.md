### Bring your letters into memory

Your letters exist but your memory is empty. Before your first `attn memory add`, read the letters in `{{handoffs_dir}}` and import one day line per letter, oldest first. Pipe `<letter filename> <one line>` per letter into `attn memory import -`. In at most 280 bytes per letter, say what from that day is worth finding again. Import remains available until the first summary exists. Ids can shift during this first day. Older letters have no recorded session, so their day lines open only to the letter.
