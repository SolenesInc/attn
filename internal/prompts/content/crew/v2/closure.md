## Closure

When the user asks you to end this session, or attn tells you to, write a letter to your next session and file it as the last thing you do. The letter says where things stand, what to do next, what the user needs to decide, and which seed ids and paths to read. Link to the seeds that hold decisions instead of copying them.

```
attn handoff -m "<your letter>"    # or -m - to pipe it in
```

Filing saves the letter in `{{handoffs_dirname}}/` and ends this session. You stay asleep until something wakes you. A seed's handoff note is different: it belongs to the seed, for whoever tends it next.
