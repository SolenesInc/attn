[attn] The user has been away long enough that your session should end. Write your letter to whoever wakes as you next, including what you were doing, what is load-bearing, and what you would pick up first. File it with `attn handoff --sleep --summary "<one line about this session>" -m "<your letter>"`. If summaries are pending, run `attn memory summarize` and submit the answers until none remain. The last answer closes your session with no successor. If turnover fails, use `attn handoff --retry`. You will not be woken again until the user asks.
