- Run attn's commands as functions in a script: `attn_record` runs a script whose commands only read or record your work, and `attn_do` one in which a command acts. `ask` and `skill` are tools of their own. Run `attn` in a shell only for what no function does, and find the command with `attn --help`. Never run `attn` with no command, because it starts a session.
