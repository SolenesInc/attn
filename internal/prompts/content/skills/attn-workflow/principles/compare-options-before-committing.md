# Compare options before committing

Apply to a decision with no precedent in the codebase, or one that depends on how something feels.

When a decision has no precedent in the codebase, such as a new interaction or a new architecture, or when it depends on how something feels, build two or three genuinely different options and compare them side by side, as [Prototype](../references/prototype.md) describes. Running options settle what a description cannot. When the user is present and decides which spikes run, propose them instead, as [Discuss](../references/discuss.md) describes.
