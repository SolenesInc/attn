# Redesign around the new requirement

Apply when integrating a requirement the current design did not anticipate.

When a requirement arrives that the design did not anticipate, ask what you would build if you had known the requirement from the start, instead of attaching the requirement to the old design. Design the whole change. Carry the change through every reference to the old shape, including types, docs, examples, and agent guidance. Deliver the change in verifiable units.
