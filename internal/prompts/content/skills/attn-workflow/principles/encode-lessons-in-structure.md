# Encode lessons in structure

Apply when the user or a reviewer corrects the same kind of mistake a second time, or when you find yourself writing the same instruction a second time.

When the user or a reviewer corrects the same kind of mistake a second time, or you write the same instruction a second time, such as one rule repeated across briefs, the instruction that failed is the symptom. Fix the whole class of mistake at the highest level that works, as [Correction](../references/correction.md) describes. When the fix falls outside the task, plant a seed for it.
