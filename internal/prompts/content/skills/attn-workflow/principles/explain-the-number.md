# Explain the number

Apply before you trust, report, or act on a number you measured.

Before you report or act on a number you measured, such as a speedup, a regression, a latency, or an eval result, name what limits it and rule out what else it could be measuring, as [Perf](../references/perf.md) describes under Explain the number. [Prove it works](prove-it-works.md) checks that an output is real; this principle checks what a number means. A number with no run count, no spread, or no named limiter is inconclusive.
