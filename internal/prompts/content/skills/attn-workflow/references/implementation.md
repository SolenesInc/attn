# Implementation

Read the agreed brief or plan and inspect the relevant code before editing. Make the change fit the codebase and resolve routine implementation choices yourself.

Do not use subagents unless explicitly asked.

When an unforeseen issue requires a consequential decision, bring the evidence, what you tried, and your recommendation to the coordinating agent identified in the brief, or to the user if none is identified. Continue independent work while waiting; wait before proceeding with work that depends on that decision.

Verify the affected behavior using repository guidance. Reuse evidence that still applies and run further checks where changes or gaps warrant them. Address review findings, then verify the corrections.

Return a reviewable change with the revision, checks performed, results, and remaining limits. Make the result readable in the conversation and durable in the seed. Follow the task's authorization for delivery steps.
