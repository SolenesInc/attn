# attn

attn no longer ships this skill. attn itself tells you what it can do:

- Run `attn --help` for the map of what attn can do.
- Run `attn skill --reference <name>` before you first use a capability.
- Never run `attn` with no command, because it starts a session.
- Never leave out a command's arguments to see what it does. Run `attn <command> --help` instead.
