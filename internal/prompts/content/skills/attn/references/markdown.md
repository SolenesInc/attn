# Markdown

To show the user a markdown document, open it in a tile next to the current session:

    attn open <path/to/file.md>

The path can be relative or absolute. To open the tile next to a different session, add `--session <session-id>`. The tile reloads whenever the file changes, so edit the file instead of opening it again.

`attn skill --reference showing` says what the tile renders and how to write a document a reader understands on the first read.

The user can mark up the document and send their notes to you as one message.
