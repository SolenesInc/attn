How to read a flow

Each row is a span: a Go function reached from the flow's entry, in the order its call sites appear in the caller. The tree comes from a static call graph (SSA + VTA), so it lists every path the code could take. Command dispatch and bus facts are linked by name, so the tree crosses the socket into the handler and jumps from a published fact to the consumers subscribed to it.

A scenario test then narrows it. The generator runs one Go test with coverage and marks each call site that executed. "Ran in scenario" keeps only those spans. A site counts as ran if it executed at any point during the test, so a shared helper can light up from another caller.
