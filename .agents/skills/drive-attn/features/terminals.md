# Terminals

A terminal is a real PTY in a tile: what the user types and what the program
prints, with scrollback, find, links and images. Every agent runs in one, and
so does every shell. People type, read, search, copy and click in a terminal.
Agents open shells on their desktop's row, run commands in the shells, read what
came back and close the shells. Terminals keep running when the app or the daemon restarts.

## Sub-features

- `terminal-input`: keys, text and paste reach the program as typed. ⌘ shortcuts stay with attn.
- `terminal-output`: what the program prints, rendered with colors, styles and the terminal's title.
- `size-owner`: when several clients show one terminal, such as the app and a phone, the one the user last typed in, pointed at or focused sets the terminal's size. A phone takes the size when it opens the terminal or types in it (the Home Gateway's `terminal_focus` and `terminal_input`). The app draws a terminal another client sized smaller than its tile at that size, scaled to fit and centered.
- `scrollback`: history above the screen, kept across relaunch.
- `find`: search the screen and scrollback, with match case.
- `blocks`: with shell integration, each command and its output form a block to copy, filter or scroll to.
- `context-menu`: right-click to copy, copy the command or output, paste, filter a block, find, scroll a block.
- `links`: ⌘-click a URL to open it in the system browser, a markdown path to dock it in a tile ([markdown.md](markdown.md)), any other path to open it.
- `session-ids`: the id of an agent the app knows, short (`ag-`), whole, or its first 8 hex digits, is marked in a terminal. The role icon of a live agent with a role stands in place of the short id's `ag-`, and copying or selecting gives the id's text. Hovering it shows the agent's card, ⌘-click opens a live agent, or the card of a closed one, which resumes it or opens the ledger on it.
- `id-labels`: while ⌘L (Ctrl+Shift+L on Linux) is held, every known id in the terminals and markdown on screen carries a letter, and the letter opens its card with the keyboard. In Asks, the ask's links and commands carry letters too, and a letter opens them as a click does. Letting go hides the letters.
- `images`: kitty graphics images drawn in the terminal, placed at a cell or by Unicode placeholder cells (as Neovim's snacks.image and `kitten icat --unicode-placeholder` place them).
- `shell-tile`: a shell in its own tile, started by the user or an agent.
- `shell-titles`: a shell's tile and sidebar name follow its program and folder.
- `focus-terminal`: one key returns typing to the active tile's terminal.
- `agent-terminals`: agents open, list, type into, run in, read, wait on and close shells. Opened shells take no focus.
- `pty-host`: every new terminal runs in one shared PTY host.

## How to get to it

### People

- Keys (`native/crates/attn-app/src/keymap.rs`): ⌘T opens a new shell on this desktop (`session.newTerminal`) by opening the new session picker with the shell chosen (`native/crates/attn-app/src/picker/mod.rs`, [agent-launch.md](agent-launch.md)). ⌘` puts typing back in the active tile's terminal (`terminal.open`). ⌘F opens find (`terminal.find`). ⌘C copies a selection. ⇧⌘C copies a selected block's command, or a selection as Markdown. ⌘=, ⌘- and ⌘0 resize the app's text, terminals included. The recipe for them is in [settings.md](settings.md).
- In the terminal, `terminal.<terminal>` (`native/crates/attn-app/src/terminal/mod.rs`): typing and paste, the find bar `terminal.<terminal>.find` ("Find", Match case, the count) (`native/crates/attn-app/src/desktop/find_bar.rs`), the block filter `terminal.<terminal>.filter` (`native/crates/attn-app/src/desktop/filter_panel.rs`), ⌘-click on links (`native/crates/attn-app/src/terminal/links.rs`), and on macOS the right-click menu (`native/crates/attn-app/src/desktop/terminal_menu.rs`) with Copy, Copy command, Copy output, Paste, Filter block output, Find, Scroll to top of block and Scroll to bottom of block. The app has no right-click menu on Linux yet.
- An id in a terminal (`native/crates/attn-app/src/terminal/ids.rs`): resting the pointer on a marked agent id opens the delegation chain's card under it, `terminal.<terminal>.agent-card` (`native/crates/attn-app/src/desktop/header_pop.rs`), and ⌘I (Ctrl+Shift+I on Linux) gives it the keyboard. A live agent's card shows its chain and Enter opens it. A closed agent's card names its harness, short id, branch and when it closed, and offers Resume (Enter or R), Ledger (L) and its seed (S). Resume goes through the ledger's reopen, and a refusal shows on the card with the action the session takes instead. ⌘-click on an id opens a live agent, gives a closed agent's card the keyboard, and opens a seed as a tile. In a popped-out tile's window the cards show in that window, and the agent, ledger, seed tile or ask they or a ⌘-click open shows in the main window, which comes to the front with the keyboard. A press in the padding around the cells opens no id or link. Markdown links the same ids ([markdown.md](markdown.md)). The app asks the daemon once, with `resolve_sessions`, about `ag-` and whole ids it does not know. An id of another profile or home, an unknown id and a commit hash stay unmarked. The icon is a `Sprite` overlay the cell renderer draws (`native/crates/attn-term/src/render.rs`). A closed agent, an agent with no role, a longer or 8-digit form, an id that wraps before its body and an id with the cursor on its `ag-` keep the plain mark. Seed ids belong to [garden.md](garden.md).
- Holding ⌘L (`terminal.labelIds`, Ctrl+Shift+L on Linux, `native/crates/attn-app/src/hints.rs`), in the main window or a popped-out tile: `terminal.<terminal>.hints` dims each terminal on screen and labels every marked id, `terminal.<terminal>.label.<n>`, each target one letter however often its id shows, two letters past 16 targets. Each box of markdown that shows ids is dimmed and labelled the same way, `words.<n>.hints` and `words.<n>.label.<n>`. With Asks, Manage crew or the fullscreen garden in front, only their ids are labelled. In Asks, the shown ask's links that a click follows, file references included, and each command's Open in terminal (`asks.command.<n>.open`) are labelled too, in the same `words.<n>` box, also while the panel's shell holds the keys; their letter follows the link or opens the command as a press does, and an id's letter still opens its card. The terminal that holds the keyboard lists the targets with their states, `terminal.<terminal>.labels`; with no such terminal, the first box of markdown that shows an id does, `words.0.labels`, or else the first terminal. A label's letter opens its target's card with the keyboard, also where the pointer shows no card. Letting go of a modifier, Escape (on Linux only: macOS takes ⌘Esc before any app sees it), a pick, the window losing focus or a desktop change hides the labels. They show and go in one step, with no fade. Keys, pastes and composed text reach nothing while they show. `id_labels`, in Settings → Appearance, is `lantern` (each id lit up, with the list) or `name` (its name in place, with no list). With no known id on screen, either says so in a corner. A browser page keeps ⌘L. A binding with no modifier does nothing, since there is nothing to hold.
- Tile header: "Rename session <name>", `tile.<pane>.rename`, on every session's tile, a shell's included (`native/crates/attn-app/src/desktop/view.rs`).
- Size: typing in a terminal (`pty_input`), moving the pointer over it (`terminal_pointer_activity`) or focusing it (`terminal_focus`, sent when the terminal takes focus by press or key) makes the app the terminal's size owner (`internal/daemon/pty_size_owner.go`). The app's `pty_resize` applies only while the app owns the size. A second client, such as `wsctl attach`, takes the size the same way.
- Where people see what agents do: a shell an agent opens appears at the row's end with a pulse and takes no focus ([desktops.md](desktops.md)), and the shell's tile shows what the agent typed and what ran.
- Their own shell: nothing. `attn terminal`, below, refuses without a calling agent.
- Splitting, zooming, moving and closing terminal tiles belong to [desktops.md](desktops.md).

### Agents

- `attn terminal` (the catalog's `internal/catalog/content/terminal.yaml`, presented by `cli/attn/src/commands/terminal/mod.rs`, run by `internal/daemon/commands_terminal.go`, `terminal_commands.go` and `terminal_move.go`): `ls [--desktop <ref> | --all] [--json]`, `open [--host <outpost|home>] [--down] [--desktop <ref>] [--cwd <dir>] [-- <command>]`, `run <terminal> "<command>" [--wait] [--timeout <seconds>] [--desktop <ref>]`, `send <terminal> (--text "<text>" | --keys C-c Escape Enter ...) [--desktop <ref>]`, `read <terminal> [--last | --scrollback [--lines <n>]]`, `wait <terminal> --until prompt|exit [--timeout <seconds>]`, `close <terminal> [--desktop <ref>]`. Typing and closing on another desktop need `--desktop`. `move` is in [desktops.md](desktops.md). `--timeout` bounds `run --wait` and `wait` in the daemon, which refuses with `timeout` and the CLI exits 124.
- Tools, with `agent_tools_enabled` on: `terminal_ls`, `terminal_open`, `terminal_run`, `terminal_send`, `terminal_read`, `terminal_move` and `terminal_close` over `/mcp`. No tool waits (D9): `terminal_run` types the command and returns the last block id, `terminal_wait` is not offered, and `terminal_read` with `mode: last` reads the finished block. `terminal_open` takes `command` as a list of words and `terminal_send` takes `keys` as a list of key names.
- `attn agent peek <session>` reads another agent's screen ([agent-state.md](agent-state.md)).
- Prompts: `attn skill --reference terminal`, on placement, reach, typing, reading and waiting (`internal/prompts/content/skills/attn/references/terminal.md`), and its capability index (`internal/prompts/content/skills/attn/SKILL.md`).

### Triggers

- New terminals start in the shared PTY host, which outlives the app and the daemon. On a machine with no usable host a new terminal fails to start, with an error that says how to get the host (`internal/daemon/pty_settings.go`). The app attaches each terminal only while its tile is drawn (`native/crates/attn-app/src/terminal/mod.rs`).

## Driving it

Preconditions:

- Use the baseline instance with its app, launched as [../SKILL.md](../SKILL.md) says, then `bridge wait '{"target":{"key":"sidebar"}}'`. `bridge state '{"of":"connection"}'` reads `"Connected"`. On Linux, run every command that reaches the app inside one `xvfb-run -a -s '-noreset -screen 0 1600x1000x24' bash -c '…'` so the display outlives each step. The chords below are the Linux ones where they differ. On macOS, ⌘T is `mod+t`, find `mod+f`, the focus key ``mod+` ``, paste `mod+v` and the desktop keys `mod+1` and `mod+2`.
- Use a shell on your machine with OSC 133 shell integration (fish, zsh or bash). `run --wait`, `read --last` and `wait --until prompt` need that integration.
- Make a proof folder with `P=$(mktemp -d /tmp/drive-attn-terminals.XXXX) && echo "export P=$P" >> $DRIVE_ENV`, and a link fixture inside the checkout with `L=$PWD/README.md && echo "export L=$L" >> $DRIVE_ENV`.
- Make an agent folder with `A=$(mktemp -d /tmp/drive-attn-terminals-agent.XXXX) && echo "export A=$A" >> $DRIVE_ENV`, and save this fixture as `$A/.attn-mock-agent.json`:

```json

  {"includes": "term-open", "actions": [
    {"type": "attn", "args": ["terminal", "open", "--", "echo", "drive-attn-open"]}]},
  {"includes": "term-list", "actions": [
    {"type": "attn", "args": ["terminal", "ls"]}]},
  {"includes": "term-run", "actions": [
    {"type": "capture", "name": "t", "pattern": "term-run (\\S+)"},
    {"type": "attn", "args": ["terminal", "run", "{{t}}", "echo drive-attn-run", "--wait"]}]},
  {"includes": "term-read", "actions": [
    {"type": "capture", "name": "t", "pattern": "term-read (\\S+)"},
    {"type": "attn", "args": ["terminal", "read", "{{t}}", "--last"]}]},
  {"includes": "term-keys", "actions": [
    {"type": "capture", "name": "t", "pattern": "term-keys (\\S+)"},
    {"type": "attn", "args": ["terminal", "send", "{{t}}", "--text", "sleep 30"]},
    {"type": "attn", "args": ["terminal", "send", "{{t}}", "--keys", "Enter"]},
    {"type": "attn", "args": ["terminal", "send", "{{t}}", "--keys", "C-c"]},
    {"type": "attn", "args": ["terminal", "wait", "{{t}}", "--until", "prompt", "--timeout", "10"]}]},
  {"includes": "term-close", "actions": [
    {"type": "capture", "name": "t", "pattern": "term-close (\\S+)"},
    {"type": "attn", "args": ["terminal", "close", "{{t}}"]}]}

```

- Save this reader as `$P/mouse-reader.sh`. It turns on SGR mouse tracking and prints each byte it reads, ESC as `ESC`, until `q`, and numbers each report after its last byte:

```bash
stty raw -echo
printf '\033[?1000h\033[?1006hREADY\r\n'
reports=0
while IFS= read -rs -n1 c; do
  case "$c" in
    $'\e') printf 'ESC' ;;
    q) break ;;
    M|m) reports=$((reports + 1)); printf '%s #%d\r\n' "$c" "$reports" ;;
    *) printf '%s' "$c" ;;
  esac
done
printf '\033[?1000l\033[?1006l'
stty sane
printf '\r\nDONE\n'
```

- Start the agent on the current desktop with `wsctl add-session --cwd $A --agent claude --label term-agent --id term-agent --place`. `<agent>` is its `runtime_id` in `wsctl list`.

- **A shell from the keyboard.** Press `sidebar.session.term-agent` to put the agent on screen. Press `mod+shift+t`: `bridge wait '{"target":{"key":"new-session"}}'` answers with `new-session.agent.shell` chosen. Press `mod+a` in `new-session.path.field`, type `<A>/`, `<A>` written out, and press `Enter`. `bridge wait '{"target":{"key":"new-session"},"gone":true}'` answers. `wsctl list` shows a new entry with `"agent": "shell"` on the current desktop. Call its id `<shell-id>`, its pane `<pane>` and its terminal `<shell>`, the `runtime_id` in `wsctl list`. `bridge wait '{"target":{"key":"terminal.<shell>"}}'` answers with the terminal's box.
- **Type and read.** Run `bridge press '{"target":{"key":"terminal.<shell>"}}'`, `bridge type '{"text":"cd <P>"}'`, `<P>` written out, and `bridge key '{"chord":"Enter"}'`. Type `echo native-$((40 + 2))` and press `Enter`. `bridge state '{"of":"terminal:<shell>","includes":"native-42"}'` waits for the rows the window drew, and one row reads `native-42` alone. `wsctl screen --id <shell>` shows the same screen from the daemon.
- **Scroll, select and copy.** Type `for i in $(seq 1 200); do echo line-$i; done` and press Enter. Run `bridge scroll '{"target":{"key":"terminal.<shell>"},"dy":-400}'`: `bridge state '{"of":"terminal-view:<shell>"}'` reads a `scrolled_back` above 0. Run `bridge drag '{"target":{"key":"terminal.<shell>"},"at":[0.01,0.3],"by":[60,40]}'`: `terminal-view` lists `Wash` overlays on the dragged rows, and `copies` holds their `line-` text. Scroll back down with `dy` `4000`.
- **Blocks.** Press the terminal, type `echo block-one` and press Enter. Find the row that reads `block-one` alone in `bridge state '{"of":"terminal:<shell>"}'`, and run `bridge press` on the terminal with `at` `[0.01, (<row> + 0.5) / <rows>]`, `<rows>` the terminal's rows: `terminal-view` reads a `block` id and lists `Outline` overlays from the command's row through the output's. On Linux, `bridge key '{"chord":"ctrl+alt+c"}'` copies the block's command, and `ctrl+shift+v` pastes `echo block-one` on the prompt; press Ctrl-U to clear it. On macOS, ⇧⌘C and ⌘V do the same, and a right-click opens the menu with Copy, Copy command, Copy output, Paste, Scroll to top of block and Scroll to bottom of block.
- **Copy as Markdown.** Type `printf 'plain \033[1mbold\033[0m \033[32mgreen\033[0m\n'` and press Enter. Find the row that reads `plain bold green` and drag across it with `bridge drag`, `at` on that row and `by` `[300,0]`. On Linux, `bridge key '{"chord":"ctrl+alt+c"}'` copies the selection as Markdown, and `ctrl+shift+v` pastes ``plain **bold** `green` `` on the prompt; press Ctrl-U to clear it. On macOS, ⇧⌘C and ⌘V do the same.
- **Filter a block (macOS).** Type `seq 1 60` and press Enter. Right-click a row of its output and pick Filter block output: `terminal.<shell>.filter.field` holds the keyboard. Type `1`: `bridge find '{"target":{"key":"terminal.<shell>.filter.count"}}'` reads `15 lines`, and the panel lists `terminal.<shell>.filter.line.<n>` for each, the matches washed yellow. Press `terminal.<shell>.filter.line.11`: the view scrolls so `12` is its top row. Press `terminal.<shell>.filter.case`, then Escape in the field: the panel goes and typing reaches the shell again. Opening find closes the filter, and opening the filter closes find.
- **Find.** Type `for i in 1 2 3; do echo find-$i-native; done` and press Enter. Press `ctrl+shift+f` on Linux or `mod+f` on macOS: `bridge wait '{"target":{"key":"terminal.<shell>.find.field"}}'` answers and the field holds the keyboard. Run `bridge type '{"text":"NATIVE"}'`: `bridge state '{"of":"terminal-view:<shell>"}'` lists `#f5c542` washes over each match, the newest at alpha 153, and `bridge find '{"target":{"key":"terminal.<shell>.find.count"}}'` reads `4/4`: three outputs and the command line that printed them. `bridge key '{"chord":"Enter"}'` steps to `3/4`, and `shift+Enter` back to `4/4`. Press `terminal.<shell>.find.case`: Match case leaves `0/0`. Press `Escape`: the bar and the washes go, and typing reaches the shell again. Letters match whatever their ASCII case; a non-ASCII letter matches only its own case.
- **⌘-click a markdown path.** The terminal resolves a relative path against the folder the shell started in, `<A>`, not against where it has since moved to, so print an absolute path. Type `echo <L>`, `<L>` written out, and press `Enter`. Find the last row that reads `<L>` in `bridge state '{"of":"terminal:<shell>"}'`. Run `bridge hold '{"mods":"mod"}'`, `bridge press` on the terminal with `at` on that row, then `bridge hold '{"mods":""}'`. A markdown tile docks: `wsctl list` holds a `tile_kind` of `markdown` whose `tile_params` is `<L>`. The docked tile can become the active tile, so press `terminal.<shell>` to put typing back in the shell before the steps below.
- **Links.** Put a stub `xdg-open` that appends its argument to `$P/opened.txt` first on the `PATH` the app launches with, so a click records the link instead of opening a browser; on macOS, click only paths. Make `$P/src/main.go`, press the terminal, type `clear; printf "see https://example.test/live and src/main.go:3\n"` and press Enter. `bridge hover` over the URL with `at` on its row: `terminal-view` lists an `Underline` overlay over the URL's columns, and none once the pointer moves off. Run `bridge hold '{"mods":"mod"}'`, `bridge press` on the URL, then `bridge hold '{"mods":""}'`: `opened.txt` holds `https://example.test/live`. Do the same on `src/main.go:3`: it holds `file://$P/src/main.go`. A plain press opens nothing.
- **Focus the terminal.** Press `tile.<pane>.rename`: the rename field holds the keyboard. Press ``mod+shift+` ``, then type `echo focus-back` and press `Enter`: `state` of `terminal:<shell>` with `includes` `focus-back` answers, so the keys reached the shell. Pressing the current desktop's sidebar row does not take typing from the terminal.
- **Shell titles.** Type `sleep 5` and press `Enter`. While the command runs, `bridge find '{"target":{"key":"sidebar.session.<shell-id>"}}'` names `sleep`. After the command ends, the folder's name returns.
- **Rename a shell.** Press `tile.<pane>.rename`, named "Rename session <name>": the rename field takes the keyboard with the old name selected. Type `build-shell` and press `Enter`. `wsctl list` shows the session's `label` as `build-shell`, and `sidebar.session.<shell-id>` names it.
- **An agent opens a shell.** Press `sidebar.session.term-agent`. Run `wsctl input --id <agent> --text "term-open" --enter`. `./attn agent peek term-agent` shows a terminal id, `<t>`. A tile opens beside the agent: `wsctl list` shows a new `"agent": "shell"` entry on the desktop, `bridge state '{"of":"desktops","includes":"<t>"}'` answers, and `bridge state '{"of":"window"}'` keeps `on_screen` on `term-agent`. `wsctl screen --id <t>` shows `drive-attn-open` printed below the command.
- **The agent lists, runs and reads.** Run `wsctl input --id <agent> --text "term-list" --enter`: peek shows the header `ID NAME AGENT STATE DESKTOP POSITION OPENED BY` and a row whose ID is the first 8 characters of `<t>` and whose OPENED BY is `term-agent`. Run `wsctl input --id <agent> --text "term-run <t>" --enter`: peek shows `drive-attn-run`. Run `wsctl input --id <agent> --text "term-read <t>" --enter`: peek shows `drive-attn-run` again, the last block's output.
- **Keys and a wait.** Run `wsctl input --id <agent> --text "term-keys <t>" --enter`. Peek shows `done` with no error. Re-read `wsctl screen --id <t>` until it shows `sleep 30` interrupted and a fresh prompt, with a deadline that fails the run.
- **The agent closes it.** Run `wsctl input --id <agent> --text "term-close <t>" --enter`: the tile goes, and `wsctl list` no longer holds `<t>`.
- **The other flags.** Make a second agent folder `B` and save a fixture in it whose turns run `terminal ls --all --json`, `terminal open --down --host home --desktop 1 --cwd <B>`, `terminal run {{t}} "echo t2-run-out" --wait --timeout 10 --desktop 1`, `terminal read {{t}} --scrollback --lines 5`, `terminal read {{t}}`, `terminal close {{t}} --desktop 1`, and `terminal send {{t}} --text exit --desktop 1`, `send --keys Enter --desktop 1` and `terminal wait {{t}} --until exit --timeout 10`, with `<B>` written out. Give each turn an `includes` that no other turn's prompt contains. Start it with `wsctl add-session --cwd $B --agent claude --label term-agent2 --id term-agent2 --place` and send each turn's prompt. `ls --all --json` lists every terminal with `terminal_id` and `opened_by`. `open` puts the shell below the agent, with the folder `<B>`. `run` shows `t2-run-out`. Both reads show the command and its output. `close --desktop 1` and the `exit` turn each remove the shell from `wsctl list`. Start a third agent whose fixture runs `terminal ls --desktop 1`: it lists the desktop's terminals.
- **What agents read.** `./attn skill --list` names `terminal`, `./attn skill --reference terminal` prints `# Terminals`, and `./attn skill` names `terminal` in the attn map.
- **The person's shell has no session.** Run `./attn terminal ls` from the instance shell. It exits 1 with `terminal: caller rule: attn terminal requires a live calling agent; run it inside an attn agent session`. `./attn terminal --help` prints the usage and exits 0.

- **Images.** Save a script `$P/kitty-image.py` that writes a 96x48 RGB gradient as kitty escapes, `\033_Ga=T,q=2,f=24,s=96,v=48,i=7,m=1;<base64>\033\\`, 4096 base64 bytes per escape with `m=0` on the last, then `after image`. - **Ids of agents and seeds.** Start `wsctl add-session --cwd $A --agent claude --label id-live --id <uuid> --place` and another, `id-closed`, with its own `--id <uuid>`, plant a seed, and close `id-closed` with `./attn agent close <id> -m "done" --source-session <id>`. ## Contexts

- **Durability across restarts**: an app or daemon restart leaves every terminal running in the PTY host, and the tile comes back with its screen and scrollback. After a machine restart, attn brings back the sessions it can resume and reaps the rest.
- **Linux**: the PTY host and `attn terminal` run the same where the daemon and CLI run on Linux. Plain Ctrl+letter belongs to the shell there, so app keys add Shift or Alt (the `LINUX` table in `native/crates/attn-app/src/keymap.rs`): Ctrl+Shift+T new shell, Ctrl+Shift+` focus the terminal, Ctrl+Shift+F find, Ctrl+Shift+L id labels, Ctrl+Shift+C copy, Ctrl+Alt+C copy a block's command, Ctrl+Shift+V paste. The right-click menu opens on macOS only.
- **Outposts**: `attn terminal open --host <outpost>` starts a shell on an outpost, and an agent's terminals default to its own machine. The home decides who owns an outpost terminal's size, and the size travels to the outpost as any resize does. While the host is offline, the tile stays, attn sends no typing, and attn refuses ⌘-click on a path, because the path lives on the other machine.
- **Profiles**: every `attn terminal` target belongs to the caller's profile. `attn terminal` does not find a terminal in another profile.
- **Performance and idle cost**: a terminal that prints nothing costs nothing. Floods hit back pressure instead of growing memory (`cmd/attnd/pty_flood_stack_test.go`, `internal/daemon/pty_stream_backpressure_wire_test.go`). `internal/daemon/pty_forward_bench_test.go` and `pty_input_bench_test.go` measure the stream. The app attaches only the terminals it draws, and hidden terminals release their drawing surface. Measure rendering changes with `docs/internal/perf-testing.md`, and export `attn debug input --tail 0` when typing stops working.
- **Harnesses**: Claude Code, Codex and plugin harnesses each run in a terminal the same way, and `attn terminal` works from any of them. Shared Codex can show one session in several tiles. Then a session id is ambiguous, and the agent passes a terminal id.
- **A program that is not reading**: input waits in that terminal's own queue, so a paste into a stuck program never slows other terminals. The queue holds 16 MiB, twice the largest frame the daemon accepts. Past it the write is refused: the tile flashes and shows that keys may not have been sent, and `attn terminal` and the daemon log name the limit. `internal/daemon/pty_input_blocked_wire_test.go` covers both backends. Keys typed after a stuck paste wait behind it, Ctrl-C included, so closing the tile is the way out. What attn delivers to an agent, such as annotations and inbox rings, is different from typing: it counts as delivered only when the program's terminal has taken all of it. A delivery the terminal does not take within 5 s is withdrawn and fails with a reason.
- **Keyboard and native input**: plain keys go to the program. ⌘ keys stay with attn, except ⌘C, which copies. ⌘` returns typing to the active tile after focus moves elsewhere. AppKit takes ⌘. before any view, so the countdown key is a File menu item, and the terminal never receives ⌘.
- **Accessibility**: the terminal that holds the keyboard is the accessibility focus, a terminal named by its tile's title and its agent's state ("Shell · idle"), so VoiceOver says which terminal takes typing. Its value is the screen as last drawn, one line per row, with the caret at the cursor, so VoiceOver reads the screen line by line. Once that terminal's output pauses for 0.3 s, VoiceOver hears the rows the output wrote, without the line being typed on, wrapped rows included: `echo hello` says "hello", and streaming output says nothing until it pauses, then at most the screen it wrote. In a shell attn started, the shell marks its prompt, so a program's question on the cursor's row ("Continue [y/N]?") is said; a terminal with no shell marks leaves the cursor's row out. Nothing is said for a screen an attach or reconnect brings back, though output after it is. Only the terminal keys type into, in the window in front, speaks: none does while Home, the Garden, a layer or any other panel holds the keys, or while another window is in front. A synchronized update is heard once it draws. The text is built only while a screen reader reads the tree. `bridge tree` shows the cursor as `selection`, `[row + 1, character, row + 1, character]`.
- **Compatibility across versions**: an update hands running terminals to the new host build (`cmd/attnd/pty_host_upgrade_stack_test.go`, `cmd/attnd/pty_upgrade_stack_test.go`), and a tile shows a notice when its terminal still runs an older build.

## Gotchas

- `attn terminal` needs a session. From the instance shell every verb but `--help` exits 1 with the caller rule. Drive `attn terminal` through the mock agent.
- ⌘T opens the new session picker with the shell chosen. ⌘T does not start a shell until you confirm a folder with Enter. Press `mod+a` in the path field before typing, so the typed folder replaces what the field starts with.
- The find count counts matches on screen rows, so a command line that wraps at the tile's width no longer matches its own text. Keep typed commands short.
- A mock turn matches the first turn whose `includes` the prompt contains, so a turn `t2-ls` also takes the prompt `t2-lsd`.
- `attn terminal ls` prints each terminal's first 8 characters as its ID. `open` prints the whole id. Either works as a target while the id names one terminal.
- `term-keys` sends Ctrl-C right after Enter. If the interrupt lands before the shell starts `sleep 30`, the command runs on and the screen never shows the interrupt. Run the turn again.
- `send --text` writes bytes and presses no Enter. Follow it with `send --keys Enter`, or use `run` for a shell command.
- `open -- <command>` and `run --wait` need OSC 133 marks. A shell without them, or `ATTN_NO_SHELL_INTEGRATION`, makes `open --` refuse before opening and leaves `run --wait` and `read --last` without blocks. `run` also needs the shell at its prompt.
- An agent may type into or move a shell freely. An agent may type into or move another agent only when one of these is true: the target is the caller, the target is below the caller in the delegation chain, or the caller is the chief. A refusal names the rule.
- ⌘-click on a URL opens the system browser on your machine. Put the stub `xdg-open` first on `PATH` on Linux, and on macOS click only paths.
- `bridge state` with `includes` matches only text, so read a terminal's `images` from the full `terminal-view` state.
- `wsctl input` counts as the user typing, so rings to that terminal wait 30 seconds after the input.
- `wsctl input` never asks for a size, so it never takes the size from the app. Use `wsctl attach`, which asks for one and stays connected, to hold a second client's size. Moving the pointer over the tile takes the size back for the app, so keep the pointer off the tile until the step presses it.
- Working but wrong: ⌘` is labeled "Focus utility terminal", but there is no utility terminal, and ⌘` puts typing back in the active tile. Drawn-only streaming applies to every terminal at once.
