# The Attn guide

How to use Attn. Read the pages here, or in your terminal: `attn guide` lists
the topics below, and `attn guide <topic>` prints one.

The guide uses the words in Attn's [glossary](../internal/glossary.md). Where
the app still shows an older word, the page tells you which label to look for.

## Tutorials

| Topic | What you get |
|---|---|
| [getting-started](tutorials/getting-started.md) | Attn installed, your first agent running, and the colors that tell you who needs you |
| [building-with-roles](tutorials/building-with-roles.md) | One change from idea to delivery: a Pathfinder plans it with you, then an Orchestrator and its Builders deliver it |

Keyboard shortcuts live in the app: Cmd+/ (Ctrl+Shift+/ on Linux) shows the
current list and lets you remap any of them. Each page names the keys it needs.
